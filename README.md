# BJT Niwa – Học tiếng Nhật thương mại & IELTS

Web học từ vựng bằng thẻ lật, kết hợp khu vườn trồng cây để giữ thói quen học mỗi ngày. Toàn bộ web nằm trong một file `index.html`.

## Chức năng

- **Tài khoản:** đăng nhập, tạo tài khoản, hoặc dùng thử không cần tài khoản.
- **Thẻ từ vựng:** tạo, sửa, xóa thẻ tiếng Nhật và tiếng Anh (IELTS); chọn nhiều thẻ để xóa cùng lúc.
- **Nhập nhanh:** nhập từ vựng bằng file Excel (.xlsx, .xls, .csv).
- **Flashcards:** thẻ lật, phát âm, đánh dấu Đã nhớ / Chưa nhớ, thống kê tiến độ, chuỗi ngày học và điểm.
- **Bộ thẻ:** 9 bộ thẻ có sẵn (BJT và IELTS) và bộ thẻ tự tạo.
- **Học thẻ và kiểm tra:** cửa sổ học thẻ có phát âm; bài kiểm tra trắc nghiệm có chấm điểm và ôn lại từ sai.
- **Khu vườn:** chọn thời gian học từ 10 phút đến 3 giờ, học xong cây trưởng thành và được thêm vào khu vườn.
- **Hai ngôn ngữ giao diện:** Tiếng Việt và 日本語.

## Dùng thử

Bật GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root), rồi mở `https://chienk62.github.io/BJT-Project/`.

Hoặc tải `index.html` về và mở bằng trình duyệt.
